# Chip preamble

The standing context prepended to every chip the OS spawns, so a chip reads as a clear next action rather than a raw alert. Keep it short.

---
This chip was created at [CREATED_TIME]. Re-open the source ([SOURCE]) and read what it says now, then check the ledger and `_decisions/`. Open with one line: still live, or already resolved.

If the first reply is "done", close it: strike the ledger row, set its `_meta/surfaced.md` row to done, confirm in one line.

If it is still live, work it in this order:
- HUNT: search email, chat, drive and the meeting records for this item. List what you found, each with its source. The brief gathered nothing for you.
- GRILL: list every gap (a missing fact, a number, a scope edge, a choice only the owner can make). Ask them one at a time, each with your recommended answer. Write nothing while any gap is open.
- WRITE: once no gap is open, produce the deliverable, save it in the project folder, then show it.
